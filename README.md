# world-layoffs-data-cleaning

## Tools Used
- MySQL

## Project Overview
This project highlights data cleaning practices in MySQL to prepare data for exploratory analysis.
In this document I:
  - Remove duplicate values
  - Standardize data columns & data types
  - Modify null or blank values
  - Remove columns/rows not needed for further analysis

## What I Learned
- How to create staging tables
- How to remove duplicates without unique row IDs
- How to update data types
- How to populate data for blank/null values
